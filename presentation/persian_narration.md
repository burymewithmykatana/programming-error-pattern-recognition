# متن فارسی ارائه

زمان هدف: ۱۲ تا ۱۴ دقیقه

## اسلاید ۱ — عنوان

در این پروژه هدف من تشخیص الگوهای خطای برنامه‌نویسی در کدهای پایتون است. سیستم از یک
baseline کلاسیک مبتنی بر TF-IDF و SVM شروع می‌کند و مسیر مقایسه با CodeBERT را نیز فراهم
می‌کند. تمرکز اصلی ارائه علاوه بر نتیجه، روی روش ارزیابی درست و محدودیت داده‌ها است.

## اسلاید ۲ — انگیزه

در کلاس‌های برنامه‌نویسی، مدرس با تعداد زیادی submission روبه‌رو است و بسیاری از اشتباه‌ها
تکراری هستند. تشخیص خودکار این الگوها می‌تواند اولویت‌بندی بازبینی و ارائه بازخورد را سریع‌تر
کند. این سیستم قرار نیست جای مدرس را بگیرد؛ نقش آن پشتیبانی از بررسی انسانی است.

## اسلاید ۳ — سؤال پژوهش

سؤال اصلی این است که آیا نمایش متنی کد می‌تواند خطاهای پرتکرار را تشخیص دهد، و آیا نتیجه‌ای
که روی داده مصنوعی به‌دست می‌آید روی داده واقعی هم قابل اتکا است؟ برای پاسخ، دو آزمایش جدا
تعریف شده تا نتیجه مصنوعی و واقعی با هم مخلوط نشوند.

## اسلاید ۴ — طبقه‌بندی هشت‌گانه

نسخه prototype شامل هشت برچسب است: کد صحیح، خطای syntax، استفاده اشتباه از متغیر، خطای
منطق حلقه، خطای شرط، خطای تعریف تابع، استفاده اشتباه از ساختار داده و ناکارآمدی الگوریتمی.
هر نمونه فعلاً فقط یک برچسب غالب دارد.

## اسلاید ۵ — دو دیتاست

دیتاست اول ۹۷۶ نمونه یکتای تولیدشده و متوازن برای هشت کلاس است. دیتاست دوم CodeContests
با submissionهای واقعی است. CodeContests نوع خطای معنایی را مشخص نمی‌کند؛ بنابراین فقط
solutionهای پذیرفته‌شده را صحیح و incorrectهایی را که parse نمی‌شوند syntax error نام‌گذاری
کردم. نسبت‌دادن برچسب‌های دیگر بدون annotation علمی نبود.

## اسلاید ۶ — pipeline

ابتدا داده اعتبارسنجی و deduplicate می‌شود. سپس fingerprint کدهای train و test مقایسه می‌شود
و در صورت overlap اجرای آزمایش متوقف می‌شود. بعد preprocessing، استخراج ویژگی، آموزش، پیش‌بینی
و تولید metrics و confusion matrix انجام می‌شود.

## اسلاید ۷ — مدل SVM

baseline از tokenهای نرمال‌شده کد، ویژگی‌های TF-IDF unigram و bigram می‌سازد و یک Linear SVM
را آموزش می‌دهد. مزیت آن سرعت، هزینه کم و قابلیت تکرارپذیری است. این مدل context عمیق یا رفتار
اجرایی برنامه را مستقیماً درک نمی‌کند.

## اسلاید ۸ — مدل CodeBERT

CodeBERT کد را با Transformer به نمایش contextual تبدیل می‌کند. تنظیمات Colab شامل طول ۲۵۶،
batch size هشت، gradient accumulation، mixed precision، early stopping و seed ثابت است.
تا زمانی که اجرای Colab تمام نشده، هیچ عددی برای CodeBERT ادعا نمی‌شود.

## اسلاید ۹ — پروتکل آزمایش

داده مصنوعی بعد از حذف تکراری‌ها به‌صورت stratified با نسبت ۷۵ به ۲۵ تقسیم شد. برای داده واقعی
از split رسمی train و test استفاده شد. تمام خروجی‌ها شامل config، زمان، predictionها، گزارش
کلاسی و confusion matrix ذخیره می‌شوند.

## اسلاید ۱۰ — نتایج

در آزمایش هشت‌کلاسه، accuracy حدود ۸۹.۸ درصد و Macro-F1 حدود ۹۰.۳ درصد است. در CodeContests
accuracy حدود ۷۰.۵ درصد ولی Macro-F1 فقط ۴۴ درصد است. علت مهم، نامتوازن بودن test است:
دو هزار نمونه صحیح در برابر فقط ۵۹ syntax error. بنابراین accuracy به‌تنهایی گمراه‌کننده است.

## اسلاید ۱۱ — دمو

در dashboard می‌توان مدل را انتخاب کرد، کد را paste کرد یا CSV آپلود کرد. خروجی شامل برچسب،
توضیح برچسب و نام مدل است. ابتدا مثال صحیح، سپس syntax error و بعد یک مثال معنایی را نمایش
می‌دهم و توضیح می‌دهم که مدل binary فقط دو برچسب را پشتیبانی می‌کند.

## اسلاید ۱۲ — جمع‌بندی

پروژه یک pipeline کامل و قابل تکرار ارائه می‌کند، اما نتیجه هشت‌کلاسه هنوز prototype است.
اعتبارسنجی واقعی نشان داد مسئله سخت‌تر از داده مصنوعی است. ادامه منطقی پروژه جمع‌آوری داده
دانشجویی ناشناس، annotation تخصصی، پشتیبانی multi-label و ارزیابی مبتنی بر تست‌های مسئله است.
